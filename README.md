# Senior Tourism Interactive Demo

Open `index.html` directly in a modern browser. No installation or build step is required.

The prototype includes:

- A high-fidelity responsive iPhone shell
- Home, Find, Share, Community, and Me navigation
- Exchange search, house detail, chat, confirmation, and travel-plan flow
- One-tap English/Chinese switching from the Home notification area, retained across every app page
- Generated Jane, Leonard, and Mr. Chen portraits plus a three-photo interactive home carousel
- App-controlled camera connection and live-stream flow
- Accessible immersive-pod reservation
- Community activity and volunteer interactions
- Vertical scrolling, horizontal main-tab swiping, modals, toasts, and persistent in-session states

To publish with GitHub Pages, upload the entire contents of this folder, including the `assets` directory, to the repository root and select the main branch root as the publishing source.
